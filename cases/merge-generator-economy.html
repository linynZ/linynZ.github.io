关于本拆解案的方法说明（请先读）

本文的输入是一张示例权重表，不是任何一款上线产品的实测配置。合成游戏的生成器权重是厂商核心配置，不公开；社区拆包数据版本不一，不足以做严谨推导。因此本文的价值不在"某款游戏的 B2 值多少体力"，而在：

层 内容 可信度
解析层 折算期望公式、体力定价的守恒式、"耗 2 体力产高一级"的价值不变性（§2–§4） 不依赖具体权重，对任何 Merge-K 生成器成立
示例层 代入示例表得到的 90% / 1.08 / 16.7 等数字（§2–§5） 只对示例表成立，换表重跑脚本即可
校验层 一个进游戏能数出来的体感锚点（§6） 待实证，本文明确标注未做

把示例当实测用是数值分析最容易犯的错误，故在此显式声明。

1. 选题说明

合成游戏（Merge Mansion、Gossip Harbor、Seaside Escape、Travel Town 一类）的核心经济只有一条链：体力 → 生成器点击 → 棋子 → 合成升级 → 交付任务 → 解锁内容。生成器权重表是整条链的第一环，几乎所有后续设计（任务定价、商店售价、活动产出、付费点）都建立在"一个 N 级棋子值多少体力"之上。

但这个换算在实践里经常被算错，最常见的错误是直掉口径：只看目标棋子的直接掉率，忽略它可以由低级棋子合成而来。本文用一张示例表把正确口径推一遍，并顺手回答一个真实的设计问题："把生成器改成每次耗 2 体力、产物等级 +1"，玩家是赚了还是亏了？

2. 示例权重表与基本量

item weight P
A1 324 0.81
A2 18 0.045
A3 18 0.045
B1 32 0.08
B2 8 0.02
合计 400 1.00

规则：二合（K = 2），每次产出耗 1 体力。

  • P(产出 A) = (324 + 18 + 18) / 400 = 90%。两个坑：权重不是百分比；分母是全表（含 B 与可能的空条目），若权重表分类型/等级两层，则类型概率只在类型层算。
  • A1 折算期望：i 级棋子 = K^(i−1) 个 1 级。E[A1] = 0.81×1 + 0.045×2 + 0.045×4 = 1.08 个 / 次。交叉验证：条件期望 1.2 × P(A) 0.9 = 1.08。
  • B1 折算期望：E[B1] = 0.08×1 + 0.02×2 = 0.12 个 / 次。

3. 一个 B2 值多少体力

折算口径：1 体力换 0.12 个 B1 → B1 = 8.33 体力 → B2 = 16.7 体力。

直掉口径：1 / P(B2) = 50 体力。这是错的——它忽略了每 12.5 次点击就来一个 B1，两个 B1 就是一个 B2。高估 3 倍，若拿它给商店定价，B2 会贵到没人买；若拿它给任务奖励定价，B2 奖励会廉价到破坏经济。

上限与分摊：16.7 是把全部体力都记在 B 头上的上限价。若 A 系也有价值（通常有，A 是主线任务用料），按价值守恒 1 体力 = v_A1·E[A1] + v_B1·E[B1] 分摊：

设 v_A1（体力） v_B1 v_B2
0 8.33 16.7
0.25 6.08 12.2
0.50 3.83 7.7

B2 的合理定价区间约 [7.7, 16.7] 体力，具体落点取决于 A 系的市场价（可由 A 系在商店/任务中的既有定价反推）。50 不在区间内。

4. 设计问题："耗 2 体力、产物 +1 级"

把整张表整体抬一级（A1→A2、…、B2→B3），每次点击耗 2 体力。

价值不变性：每次产出的 B1 等价物 = 原来的 ×2（每个棋子都翻倍），体力也 ×2，单位体力期望仍是 0.12。B2 定价不变。 这个结论对任意权重表、任意 K 都成立，因为"全表 +1 级"等价于对折算期望乘常数 K，而体力乘的是同一个常数（当且仅当新体力 = K × 旧体力）。

直掉口径在这里会得出"B2 现在 100 体力"或"25 体力"之类的结论，再次说明它不可靠。

真正变化的三样东西（同样花 100 体力）：

量 原模式 新模式
产出棋子数 100 50
手动合成 / 拖拽次数 基准 约减半
B1 等价物总量的方差 14.6 29.1（×2）

设计意图反推：这是便利性售卖（省棋盘格、省操作），不是产出加成；同时方差翻倍意味着短期"欧非"体感更强。若产品想把它做成付费加成点，需要叠加真实收益，例如定价 1.8 体力（而非 2）→ 单位体力产出 +11.1%；1.5 体力 → +33.3%。要不要给这个收益，取决于它是长期开关（会永久抬高产出，冲击整条任务定价）还是限时道具（可控）。

5. 定价对权重的敏感度

其余权重不变，只动一项：

变动 B2 定价（体力）
B2 权重 4 / 8 / 16 / 32 19.8 / 16.7 / 12.8 / 8.8
B1 权重 16 / 32 / 64 24.0 / 16.7 / 10.8
A3 权重 0 / 18 / 72 15.9 / 16.7 / 18.9

同样翻倍，B1 权重的影响（−35%）大于 B2 自身（−23%）——B1 对 E[B1] 的贡献 0.08 是 B2 贡献 0.04 的两倍。换句话说，调 B 系稀有度时，动低级权重比动高级权重杠杆更大，而且对玩家更不可见。A 系权重只通过总权重分母稀释 B。

6. 体感锚点与后续实证（未做）

本文所有数字来自示例表，唯一能把模型和真实产品接上的，是一个进游戏能数出来的量：

每 16.7 次点击应出现 1 个 B2 等价物（含 2 个 B1 合成）。数 200 次点击即可核对。

若实测显著多于 17 次，说明真实表存在保底 / 伪随机，或示例表的 B1 权重偏高；显著少于则反之。这一步需要实际游玩记录，本文未做，标为后续。

三合（K = 3）下同一张表：E[A1] = 1.35，E[B1] = 0.14，B2 = 21.4 体力——底数换掉即可，方法不变。
