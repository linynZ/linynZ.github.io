2. 设计目标与体验目标

一句话核心体验：答题即攻击，知识即战力——你懂多少历史，就能打出多少伤害。

目标 对应 GDD 支柱 落地规则
学习不是外挂小游戏，而是战斗本体 P1 Knowledge IS power 每次出招必抽一题，答题质量直接乘进伤害
答错不羞辱、失败不清进度 P2 Gentle learning 答错仍造成 0.2× 伤害；战败保留记忆/碎片进度，弹窗重试
让玩家"自愿"去答不熟悉的领域 P1 + P3 五元素克制环 = 五知识域，Boss 分阶段换属性逼迫换域
米哈游级战斗手感 P4 Anime game 碎裂转场、会心切入、卡帧、Boss 换相定格

目标玩家：对历史文明有兴趣的二次元向 RPG 玩家（对标原神/星铁受众）；教育场景下的中学至大学生。设计上不假设玩家有题库知识，"错"是被允许的默认状态。

3. 系统概述

玩家与 1~n 个"错乱体"回合制对决。玩家每回合选一个技能，技能绑定一种元素（=知识域），系统从当前时代题库的该知识域抽一道四选一限时题；答题结果（快答/答对/答错/超时）转化为伤害倍率。敌人不答题，只按数值回击（±15% 浮动）。Boss 随 HP 下降切换属性，玩家必须轮换知识域。伤害、元素、答题倍率全部是无副作用的纯函数，可离线单测。

                  ┌──────────────── 回合开始：专注 +3（上限 8）
                  ▼
   选技能（元素 E，消耗专注）
                  │
   抽题：region=当前时代 ∧ category=E ∧ 本战未出 ∧ [Boss: Bloom≥understand]
                  │  12s 限时，选项显示层洗牌
                  ▼
   答题质量 q ∈ {快答1.5, 答对1.0, 答错0.2, 超时0.1}
                  │
   dmg = max(1,(power+ATK-DEF)) × 克制(1.25/1.0/0.8) × q
                  │
   结算 → 显示正确答案+解析 → Boss 相位检查（换属性）
                  │
   敌方回合：dmg = max(1, ATK敌-DEF玩家) × (1±0.15)
                  │
   胜：EXP/分数/记忆+40 ── 败：DefeatPanel 重试（进度保留）

4. 规则详述

4.1 回合流程

步骤 规则
回合起手 玩家专注按 focusRegenPerTurn 回复，再列出"等级达标且专注够付"的技能
无可用技能 提示"专注不足"，跳过本回合（设计上不会发生，见 §5.2 专注契约）
出招 扣专注 → 抽题 → 答题 → 结算伤害 → 展示解析 → Boss 相位检查
群体技 AllEnemies 对所有存活敌人各结算一次同额伤害
自身技 Self 类型：治疗量 = power × 答题倍率（当前版本无自身技资产，机制保留）
敌方回合 每个存活敌人依次：预警演出 → 伤害 → 命中演出
终止 敌全灭=胜；玩家 HP=0=败；100 回合硬上限视为弃权（防治疗死循环）

4.2 五元素 = 五知识域

元素 知识域 题库 category 克制（×1.25）
建筑 Architecture 建筑、工程、纪念物 Architecture 文化
文化 Culture 艺术、文字、日常生活 Culture 哲思
哲思 Philosophy 思想、宗教、律法 Philosophy 地理
地理 Geography 疆域、贸易、城市 Geography 历史
历史 History 事件、君主、年代 History 建筑

克制环是闭合五边形：进攻方克"环上下一个"（×1.25），被"环上上一个"抗（×0.8），其余含同属性为 ×1.0。元素枚举与题库 category 字段 1:1 同名——技能不只决定倍率，还决定你被问哪个领域的题。

4.3 答题质量 → 伤害

结果 判定 倍率 设计意图
快答 CorrectFast 答对且用时 ≤ fastAnswerThreshold（5s） ×1.5 精通奖励，触发会心切入+卡帧
答对 Correct 答对 ×1.0 标准命中
答错 Wrong 选错 ×0.2 "擦伤"——保留行动价值但强耦合知识
超时 TimedOut 12s 内未选 ×0.1 犹豫比犯错更糟，制造时间压力
无题 该时代该域无题（数据缺失） 视为 Correct + 控制台警告 不惩罚玩家，但暴露配置错误

4.4 专注经济

参数 值 说明
上限 maxFocus 8
起始 startFocus 5 首回合回复后为 8，可立刻放群体技
每回合回复 focusRegenPerTurn 3 ≥ 单体技费用，保证任何回合都有招可出
单体技费用 3 建筑/哲思/地理/历史
群体技费用 4 文化（AoE）
觉醒态额外回复 +2 仅终局二阶段

节奏设计：单体技可无限连发；文化 AoE 需要"攒一回合"；专注不会归零锁死（见 §8 迭代 1）。

4.5 抽题规则（四层过滤，顺序固定）

层 规则 饥饿保护
① 地区隔离（硬） 只抽 region == 当前时代 的题；域内无题则回退到同地区任意域；地区无题返回空 绝不跨地区
② 本战去重（硬） 本场已出题排除，直到该池全部出过一遍 排空则整池回绕
③ Bloom 偏好（Boss） Boss 战优先 bloom ≥ understand 无则回退全池
④ 跨战去重（软） 会话内最近 15 题回避 排空则整池回绕
显示层 四个选项 Fisher-Yates 洗牌，点击槽位映射回原 index 再判分 数据文件不动

顺序为什么是②在③前：Boss 的 understand+ 池极小（每域 3~14 题），若先按 Bloom 过滤再去重，会在 remember 题还没见过时就重复 understand 题——"新鲜度优先于层级"。

终局 70_Finale 的 regionId 留空 → 走"全 500 题按域抽"路径，作为五时代总复习。

4.6 Boss 门

条件 规则
碎片条件 collectedFragments ≥ fragmentCount
记忆条件 该图记忆修复度达 memoryTarget（碎片 +20 / 净化战 +40 / 勘误道具 +3）
判定 两条件同时满足才可交互；未启用的条件不阻塞
开门演出 粒子爆发 + 横幅，明确"你已准备好"

4.7 Boss 多相位

phase = floor((1 − HP%) × 相位数)，只升不降；换相时 Boss 元素切换并触发定格演出。

Boss 相位序列 换相血线
华夏·大错乱 历史→建筑→文化 66.7% / 33.3%
埃及 建筑→地理→历史 同上
希腊 哲思→文化→历史 同上
罗马 建筑→历史→地理 同上
丝路 地理→文化→历史 同上
终局·本源 历史→建筑→文化→哲思→地理 每 20%

4.8 终局二段式例外

阶段 规则
一阶段 Unyielding 抽题答题照常，对 Boss 伤害钳为 0，飘字"被时间消解"；敌方照常攻击
觉醒节点 回合 ≥ 3 或 玩家 HP < 50%（先到为准）→ 战斗脚本化中断（无胜负、无奖励），存档标记 finaleAwakened
二阶段觉醒态 ATK ×1.5、专注回复 +2、习得「星芒之契」（power 40 / 费 4，每次使用元素在五域随机，赌克制 vs 稳打）
谬误揭露 二阶段限定，同一知识域连续答对 2 题 → Boss DEF ×0.75，每战一次
重试 战败后直接以觉醒态重开二阶段，不重播困境戏

5. 数值设计

5.1 伤害公式

玩家 → 敌：dmg = max(1, round( max(1, power + ATK − DEF) × 克制 × 答题倍率 ))
敌 → 玩家：dmg = max(1, round( max(1, ATK敌 − DEF玩家) × (1 ± 0.15) ))   // 无元素、无答题
经验：EXP = baseExp + 敌等级×5；升级需求 = 50 + 25L + 5L²

6. 交互与表现（设计意图与规则）

节点 规则 意图
入战 碎片碎裂转场（Persona 式，6 条碎片错峰入/出 0.17s/0.20s）→ 双立绘 VS 滑入 "被拉进对决"的仪式感
出题 题干 + 4 选项 + 环形倒计时；倒计时用非缩放时间，暂停菜单与查证卡打开时暂停；剩 40%/20% 变色 卡帧/暂停不偷时间
证据回响 题目若链接到已解锁的日志条目，每战一次可点开查阅 奖励探索，读过的知识能救场
揭晓 正确答案高亮 + 解析文本（答错也显示） 每题都是一次教学
会心 快答 → 切入横幅（入 0.14s/停 0.44s/出 0.16s）；命中瞬间卡帧 0.07s（timeScale 0.05） 星铁式"重击"
Boss 换相 定格 0.30s + 立绘 1.28× 冲击缩放 + 元素环 + 横幅；与会心卡帧共用一个截止时钟，短卡帧不会截断长定格 让"该换知识域了"被看见
星尘托盘 每答对当场凝聚一颗星尘（快答金色、答对蓝白，答错不生成） 缺席即反馈，无红叉
结算 星尘汇聚 → 光芒档位：星灿（全对且快答≥半数）/ 星辉（正确率≥60%）/ 微光（其余，仍是光）；纯表现无数值奖励 拒绝 S/A/B 字母评级，贴合"温柔学习"
战败 静默模态面板：出生点重试 / 回枢纽 不是 Game Over 尖叫
首战教学 首场真实战斗在关键节点弹 3~4 张提示卡，之后永不再出 讲清"答题=攻击"

9. 设计取舍与已知局限

取舍 决策 理由
敌人为什么不答题 敌人只按数值回击 对决对象是"玩家 vs 玩家所知"，敌人答题会把焦点变成 AI 演出；±15% 浮动已提供不确定性
答错为什么是 0.2 不归零 保留最低 1 点伤害 教育"再尝试"原则：行动权不被没收；单测锁定 wrong > 0
超时为什么比答错更低 0.1 < 0.2 逼玩家在 12s 内做判断，杜绝"等到最后一秒再猜"
结算不做字母评级 三档光芒、纯表现 冷评分与"温柔学习"冲突，且零平衡耦合
洗牌放显示层不改数据 JSON 原样保留 数据即论文证据；显示层修复覆盖全部 500 题
Bloom 分布 470 remember / 30 understand / 0 apply / 0 analyze AI 批量生题的诚实局限；Boss 调度只能"利用现有深度"，不能凭空创造高阶题
终局 Boss 无等级缩放 固定 2000/50/19 封版审计观察：Lv1 需近乎全对 56 回合、Lv20+ 时 Boss 单次伤害≈2；正常五时代成长曲线下两端不可达，跳关档由开发者补偿指令覆盖
玩家无元素弱点 敌方攻击一律中性 减少一层玩家需记忆的规则，把认知负荷留给题目
