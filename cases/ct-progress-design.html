2. 设计目标与体验目标

目标 说明
每一件事都在推同一个进度条 探索里的一切动作——拾碎片、净化错乱体、勘误展台——都汇入本时代唯一的"记忆修复度"；不打架的活动也能可视化地推进 Boss 解锁。玩家不需要理解多套货币，只需看一根条。
温柔学习支柱 没有掉落惩罚、没有死亡：掉出地图边界由同伴璇玑"拉回"并讲一句时代科普；答错题只降伤不扣命。进度系统里所有"失败"都只是"还没完成"。
自由探索永不死锁 时代图是开放小箱庭，玩家可先摸碎片、先打游荡错乱体、甚至先做后面阶段的事。任务系统承诺：任何顺序都不会卡住主线。
宏观进度可见证 每颗记忆星晶都对应一个"星醒"演出：回到枢纽时下一扇门当面苏醒，而不是默默变成可交互。

3. 系统概述与循环

枢纽·星引宫 ──进入已苏醒的时代门──▶ 时代浮岛（探索）
   ▲                                   ├─ 与 NPC 对话 → 任务阶段 / 日志
   │                                   ├─ 拾取记忆碎片（+20）─┐
   │                                   ├─ 净化错乱体（+30/+40）├─▶ 记忆修复度 0→target
   │                                   └─ 勘误展台（+3，仅华夏）┘
   │                      碎片 3/3 且 记忆满 ──▶ Boss 门解封（粒子+横幅+过场 gate_<era>）
   │                                   └─ 击败大错乱 → 主线最终阶段完成
   └──── 授记忆星晶 → 即时存档 → clear 过场 → 自动返枢纽 → 下一扇门"星醒"
   ×5 ──▶ 五星集齐 → 枢纽中央深渊裂隙 → 终局二段式决战

系统之间只通过事件耦合：碎片拾取 / 战斗结束 / 对话完成 / 记忆满 四类事件广播，任务、门、HUD、存档各自订阅。

4. 规则详述

4.1 记忆修复度

规则 实装
计量单位 每张时代图独立累计整数"记忆点"，与该图 memoryTarget 相除得 0–1 修复度；HUD 显示百分比
目标值 由每张图的 MapDescriptor.memoryTarget 配置：华夏 100，尼罗/爱琴/永恒之城/丝路各 80，枢纽与终局 0（无记忆机制，HUD 隐藏）
来源 碎片 +20；游荡错乱体 +40（任务指定那只）/ +30（其余）；华夏勘误展台答对 +3；Boss 本身 +0
上限 数值不封顶（可超过 target），显示层钳到 100%；"记忆满"事件只触发一次，触发记录随存档持久化，读档不重放
满条效果 广播 OnMemoryFull → Boss 门条件之一置真 → 横幅"记忆修复圆满 · 封印松动" → 任务 ReachMemory 类目标可推进

经济超供（防软锁核心）：每图可得记忆总量都显著高于 target，玩家不必"做完所有事"就能开门。

时代 target 碎片 3×20 游荡错乱体 其他 总供给 开门最少需做
华夏 100 60 谣言 40 + 谬误 40 勘误 9×3=27 167 3 碎片（门硬性）+ 任一 40 错乱体
尼罗 80 60 流沙 40 + 遗忘 30 + 伪史 30 — 160 3 碎片 + 任一错乱体
爱琴 80 60 诡辩 40 + 谬误 30 + 遗忘 30 — 160 同上
永恒之城 80 60 讹传 40 + 谬误 30 + 遗忘 30 — 160 同上
丝路 80 60 流言 40 + 遗忘 30 + 谬误 30 — 160 同上

GDD §9 写的是"0–100、经济超供 ≥140"，实装后华夏保留 100、后四图降到 80 并各多放一只 30 分错乱体，超供比从 1.4× 提到 2×。但主线任务第二阶段指定净化那只 40 分错乱体，所以实际最短路径 = 3 碎片 + 任务指定错乱体，其余错乱体全是可选内容。

4.2 碎片系统

规则 实装
数量与命名 每图固定 3 枚，id 为 frag_<era>_1..3；Boss 门与任务都按前缀 frag_<era> 计数，不关心具体哪枚
拾取 E 键交互；同 id 二次拾取被忽略（去重）
持久化 逐 ID 存档，不存"数量"。读档后进图时已拾碎片在 Start 自毁，杜绝重刷记忆/分数、以及"追踪器显示已收集但场上还有水晶"的错位
表现 运行时自动升级为程序化"星空蓝"六棱双锥水晶 + 火花 + 点光；拾取时 HUD 弹 "+20 记忆" 并脉冲

悬浮碎片边界与坠落救援（世界观：每张时代图是漂在"之海"上的记忆碎片）

层 设计
视觉填充层 地图最低点下方铺大面积纯视觉平面（无碰撞），按时代换"海"：记忆之海 / 沙海 / 酒色深海 / 虚空 / 荒原星夜，配远景环与雾，让边界读作地平线而非空气墙
FallRescue 每张时代图自动生成；以本图最低出生点为基准，玩家下落超过 45 m 即触发；传回 default 出生点并向下射线贴地；2 s 冷却；30 次校准失败后自禁用
非死亡 明确不是掉落死亡（参考空洞骑士危害重生但去掉扣血）——把边界 bug 转化为角色时刻
台词 璇玑 fall_rescue bark，按时代过滤，每条含一句"XX 之外是什么"的介绍（见 §6）

4.3 Boss 双条件门

规则 实装
条件 requiresAllFragments（前缀碎片数 ≥ fragmentCount=3）且 requiresMemoryFull（本图记忆满）；五个时代 Boss 两项全开，游荡错乱体两项全关，终局 Boss 无门
判定 纯谓词 BattleGate.IsOpen：未启用的条件永不阻塞，启用的条件必须全部满足；7 个 EditMode 用例覆盖无门/只碎片/只记忆/双门
未开门交互 E 键无效，提示第一条未满足的条件（先碎片"需集齐记忆碎片（n/3）"，再"记忆尚未修复，无法挑战"），让玩家知道下一步做什么
解封演出 门从锁到开的那一帧：封印紫粒子爆发 + 横幅"封印松动 · 大错乱苏醒" + 封印破裂音效 + 一次性过场 gate_<era>（五时代各一段，只播一次）
挑战 开门后 E 键先播一次性 Boss 前置过场 <era>_boss_intro，再进战斗；Boss 胜利记忆 +0（门已开，不需要）
工具防回归 内容重建工具设碎片门时不触碰记忆门标志，所以重跑工具不会把双门降级成单门（这是真踩过的坑）

4.4 任务系统

规则 实装
结构 每时代一条主线（quest_<era>_main），5 条并行存活；定义为 ScriptableObject：有序阶段列表 → 每阶段若干目标（类型/目标 id/所需次数/追踪器标签）
目标类型 TalkTo（npcId）/ Defeat（encounterId 或 any）/ Collect（碎片 id 前缀）/ ReachMemory（地图名）——ReachMemory 已实现但五条主线未使用
启动 首次进入某时代自动开始该图主线；已存在则跳过
推进 对话完成 / 战斗胜利 / 碎片拾取 / 记忆满 四类事件驱动，同时推进所有存活任务（不只当前图）
阶段激活时补记 每次进入新阶段先清进度，再从持久记录回填：已拾碎片集合、已净化 encounter 集合、已对话 NPC 集合、记忆是否已满。回填后若阶段已满足则链式跳到下一阶段，可连跳多阶
完成 最后阶段完成 → 广播完成事件 → 时代收尾控制器授星晶
追踪器 只显示当前图的任务；标签文案与错乱体交互提示同用敌人名（"净化「流沙之讹」"），避免玩家对不上

4.5 时代链与记忆星晶

规则 实装
星晶 每时代主线完成授 1 枚，按 mapId 记录（集合，不可重复得）；只有 quest_<era>_main 形式且非 hub 的任务才算时代主线
顺序解锁 固定顺序 china → egypt → greece → rome → trade；第 i 个时代解锁条件 = 持有第 i-1 个时代的星晶（必须是前一个，不是任意一个）；新档只开华夏
已建成白名单 顺序解锁但内容未建成的时代显示"正在凝聚"（会"微动"但不开）；五时代现已全部建成，此态仅剩机制
封印门交互 E 键不是死按钮：璇玑用 portal_sealed / portal_condensing 台词解释（4 s 冷却）
授晶后流程 授星晶 → 立即存档 → 播一次 clear_<era> 过场（无过场则等 2 s）→ 传送回枢纽 from<Era> 出生点
星醒演出 回枢纽后等进入 Exploring 再 +1.5 s，找到"已解锁但未见证"的门播 Awaken（灰变彩、法阵展开、灯亮）+ 璇玑 star_wake 台词；见证记录按时代 id 持久化，华夏预置为已见证
终局解锁 持有全部已建成时代的星晶（当前 = 5 枚）→ 回枢纽后播一次 finale_demo → 在五门几何中心召唤深渊裂隙 → 进入 70_Finale
单测 EraCompletion 纯函数 28 个 TestCase：首时代恒开、需前一枚而非任一枚、大小写、未知时代锁死、链走查、已建成表与场景名同步

4.6 存档点与持久化

存档时机 说明
进入任一地图 检查点
战斗胜利 延迟 1 s 再存，让触发器先写完净化与记忆
终局一阶段脚本化结束 觉醒是真实进度拍，也存
授星晶 立即存（封包审核加固项）
退出游戏 自动存
终幕 改写复活点为枢纽后存
主菜单未开局 拒绝存档，防止空档覆盖有效档

写入方式：临时文件 → 原子替换 → 保留 .bak；主档损坏自动用备份恢复；版本号不符（当前 "1.1"）不读不删、改名备份。

6. 交互与表现

触点 表现
HUD 记忆条 左上自建条，记忆青色；仅当前图有 target 且处于探索态时显示；每次增量弹 "+N 记忆" 上浮渐隐 1.1 s、条体白闪脉冲、拾取音效；条体以 0.8/s 速度追赶目标值
记忆满 横幅"记忆修复圆满 · 封印松动" + 成功音效
门解封 封印紫爆发粒子 + 横幅"封印松动 · 大错乱苏醒" + sfx_seal_break + 过场 gate_<era>
门未开 交互提示直接告诉缺什么：碎片 n/3，或"记忆尚未修复，无法挑战"
星醒 门体 Awaken：爆发粒子 → 灰变彩 → 法阵放大展开 → 灯光渐亮；璇玑："看——那扇门醒了！你点亮的星，正在替你开路。" / "星轨接通了！新的时代在呼唤你呢，旅者。"
封印门 璇玑："记忆尚未凝聚的门，推不开的。先把眼前的时代修复好吧。" 等 3 条
坠落救援 华夏："哇——接住！浮岛之外是环抱华夏的记忆之海，想游泳也得先问过本座！" / 尼罗："神庙之外是无边的流沙之海，被吞下去的记忆，本座也捞不回来！" / 爱琴："浮岛之外是酒色的深海。诗人掉下去，也只会变成一首挽歌。" / 永恒之城："条条大路通罗马，可没有一条通向那底下。" / 丝路："商路之外是驼队都不敢走的荒原星夜。" + 2 条通用兜底

7. 防软锁与容错设计

# 可能的死锁 / 失效 对应机制
1 玩家先拾碎片/先打错乱体，任务还停在"拜会 NPC"阶段，事件已过、物体已销毁 阶段激活时从持久记录补记：碎片集合、净化集合、对话集合、记忆满状态；链式跳阶
2 先做了后面阶段的事再读档 补记读的是存档里的集合，不是场景对象，跨读档有效
3 跨图完成前置（例如任务阶段在别的图激活） NPC 对话记录存于全局集合而非场景 NPC；早期版本按场景扫描导致跨图丢记录，已改
4 记忆总量刚好等于 target，漏一个就开不了门 经济超供 1.67×–2×；碎片是硬条件，错乱体只需任一只
5 读档后"记忆满"事件重放 → 重复开门/重复推任务 fullMemoryMaps 持久化，满事件一生一次
6 读档后已拾碎片/已净化错乱体复活 → 重刷记忆 二者 Start 时自查记录并自毁 / 隐藏；只有 oneShot 的 encounter 才写净化记录（终局 Boss 可重打）
7 授星晶后返枢纽途中崩溃 → 星晶丢失 授晶后立即存档（07-19 封包审核加固）
8 只在退出时存档 → 崩溃丢整局 进图 + 战斗胜利检查点；战斗后延迟 1 s 保证净化/记忆先落地
9 从主菜单退出把空档覆盖有效档 未开局拒绝写盘
10 存档写到一半断电 临时文件 + 原子替换 + .bak；主档坏自动恢复
11 旧版本存档字段错位 版本不符只备份不加载，也不删除
12 星醒演出重复播放"风暴" 见证标记改为演出开始即写（原来延迟 4.5 s，玩家立刻进门导致标记没落地）
13 走出地图边界困死在浮岛下方 FallRescue 45 m 传回 + 贴地射线；填充层无碰撞是有意为之（有碰撞反而困死）
14 顺序解锁但内容没建成的时代 已建成白名单：门显示"正在凝聚"且不可进，星晶照发
15 Boss 门在 Unity 工具重跑后被降级 碎片门设置不触碰记忆门标志

9. 设计取舍与局限

取舍 理由 / 代价
门用"碎片全收 + 记忆满"双条件，而不是单一记忆条 单条会让玩家跳过全部碎片直接刷错乱体；碎片是探索引导，硬性保留。代价：碎片必须都放在单跳可达处，关卡放置成本高（埃及重写过一次放置逻辑）
记忆超供 2× 而非精确 宁可让部分错乱体变成"可选内容"，也不让漏一处就卡门；教育游戏的目标是让玩家多打题，不是逼玩家找齐
任务用"补记"而非"锁门" 不锁任何世界物体，玩家自由度最高；代价是每个目标类型都要有对应的持久记录，新加目标类型必须同时加记录源
五条主线完全同构（4 阶段） 内容产能与工具泛化优先（新增时代=一条配置）；代价是任务缺乏变化，ReachMemory 类型实现了但未被使用
时代严格顺序解锁 匹配难度曲线与终局等级预期（≈Lv6）；代价是玩家不能自选时代
存档只有单槽 + 自动 减少 UI 与手动步骤；代价是无法回溯多个存档
勘误展台只做华夏试点 审计建议的推理型内容，未来推广需每时代写 9 张物品卡
