==============================================================================
总权重 = 400
  A1: weight  324  ->  P = 324/400 = 0.8100
  A2: weight   18  ->  P = 18/400 = 0.0450
  A3: weight   18  ->  P = 18/400 = 0.0450
  B1: weight   32  ->  P = 32/400 = 0.0800
  B2: weight    8  ->  P = 8/400 = 0.0200

P(产出 A) = 9/10 = 0.9000   P(产出 B) = 0.1000
每次产出的 A1 等价物期望 E[A1] = Σ P(A_i)·2^(i-1) = 27/25 = 1.0800
  交叉验证：条件期望 E[A1|A] = 1.2000 × P(A) 0.9000 = 1.0800
每次产出的 B1 等价物期望 E[B1] = 3/25 = 0.1200

§2 单位体力价值与稀有棋子定价
==============================================================================
折算口径：B1 = 1/0.1200 = 8.333 体力 -> B2 = ×2 = 16.667 体力
直掉口径：B2 = 1/P(B2) = 50.000 体力   （忽略了 B1 可合成，高估 3.00 倍）

折算口径把全部体力记在 B 头上，是 B2 的**上限价**。若 A 也有价值，按价值守恒分摊：
   1 体力 = v_A1·E[A1] + v_B1·E[B1]
   设 v_A1 = 0.00 体力 -> v_B1 = 8.333  v_B2 = 16.667 体力
   设 v_A1 = 0.25 体力 -> v_B1 = 6.083  v_B2 = 12.167 体力
   设 v_A1 = 0.50 体力 -> v_B1 = 3.833  v_B2 = 7.667 体力
   设 v_A1 = 0.75 体力 -> v_B1 = 1.583  v_B2 = 3.167 体力
=> B2 的合理定价区间约 [7.7, 16.7] 体力，取决于 A 系的市场价；直掉口径的 50 不在区间内。

==============================================================================
§3 改动：每次耗 2 体力、产物等级 +1 —— 价值不变性证明
==============================================================================
新表：{'A2': 324, 'A3': 18, 'A4': 18, 'B2': 32, 'B3': 8}
每次产出 E[B1] = 0.2400（= 原来的 ×2），每次耗体力 2
单位体力 E[B1] = 0.1200  vs 原模式 0.1200  ->  相等
因此 B2 定价不变（折算口径仍 16.667 体力）；直掉口径会误算成 1·2/P(B2') = 100.0 体力，再次说明直掉口径不可靠。

真正变化的量（同样花 N 体力）：
   棋子数量：100 个 -> 50 个（棋盘占用 / 手动操作次数减半 = 便利性）
   B1 等价物总量方差：14.56 -> 29.12（×2.00，波动更大）
   设计意图反推：这是**便利性售卖**，不是产出加成。若想做成付费加成点，需叠加真实收益，例如：
     耗 1.8 体力（而非 2）-> 单位体力产出 +11.1%
     耗 1.5 体力（而非 2）-> 单位体力产出 +33.3%

§4 定价对权重的敏感度（其余权重不变）
==============================================================================
基准 B2 = 16.67 体力
   B2=4: 19.80 | B2=8: 16.67 | B2=16: 12.75 | B2=32: 8.83
   B1=16: 24.00 | B1=32: 16.67 | B1=64: 10.80
