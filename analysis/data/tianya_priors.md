## 案一 · 战斗属性转换
1. 天刀的属性→百分比是 `p = x/(x+K)` 型饱和曲线，K 随角色等级线性或分段抬升；升一个大版本（等级上限 +5 或 +10）后同样面板的会心率会掉 3–6 个百分点。
2. 会心与韧性、命中与闪避是直接相减或"同型函数相减"的对抗关系；论剑里堆韧性的性价比高于堆会心，因为韧性同时压对方会心率和会伤。
3. 远程门派（唐门 / 天香 / 五毒）的最优堆法是"命中先够、会心堆到边际收益拐点、剩下全会伤"，拐点大约在会心率 40–50% 附近。
4. 论剑不做属性标准化（装备差距直接带入），但有等级压制/属性缩放；装备差一个大档位在论剑里体现为期望伤害差 20–30%。
5. 官方每个版本主要通过抬 K（分母）而不是砍属性来做数值通胀，所以老装备"缩水"是隐性的。

## 案二 · 身份与日常时间预算
1. 拿满每日活跃度需要 60–90 分钟，其中帮会任务 + 话本 + 剑荡占一半以上。
2. 一天需要打开的独立"窗口"（活动/面板）≥ 8 个，比 Gossip Harbor 的 5.7 更多；MMO 的打卡链本来就长。
3. 身份里"乐伶 / 文士"是时间效率最高的（低操作、可挂机），"杀手 / 游侠"是时间效率最低但产出最稀缺的。
4. 中度玩家（每天 1–2 小时）刚好能拿满活跃度 + 做一个身份，做不了第二个身份和论剑；重度玩家的增量主要来自帮会/论剑而非日常。
5. 付费能替代的"必做时间"不到 30%：月卡/直购主要买养成材料，买不掉话本/帮会这些强制在线内容。

## 用户锚点（口述）
- 门派：唐门 / 天香 / 五毒（远程或辅助）；460 小时。
- 日常：中度，每天 1–2 小时，日常全做 + 身份。
- 未问到：论剑段位、付费、弃坑原因、常用身份——面试前若需要再问。
